# Руководство пользователя Tempus

Tempus — настольное приложение для учёта времени, затраченного на различные задачи. Приложение интегрируется с системным треем, поддерживает синхронизацию с YouTrack и импорт встреч из KTalk.

## Начало работы

При запуске Tempus открывается главное окно с записями за выбранный период. Приложение также размещает иконку в системном трее для быстрого доступа.

### Хранение данных

Данные хранятся локально в базе данных SQLite:
- **Windows**: `%APPDATA%/tempus/`
- **Linux**: `~/.local/share/tempus/`
- **macOS**: `~/Library/Application Support/tempus/`

## Главное окно

Главное окно состоит из нескольких областей:

### Панель кнопок

| Кнопка                 | Описание |
|------------------------|----------|
| **Старт**              | Начать отслеживание новой активности |
| **Стоп**               | Завершить текущее отслеживание |
| **Экспорт CSV**        | Сохранить записи в CSV-файл |
| **Экспорт в YouTrack** | Отправить записи в YouTrack (требуется настройка) |
| **Импорт из KTalk**    | Импортировать записи из встреч KTalk |
| **Настройки**          | Открыть настройки приложения |

### Выбор периода

Выберите, какие записи отображать:
- **Календари «От» и «До»**: нажмите для выбора даты
- **Быстрые фильтры**:
  - **Сегодня**: показать только сегодняшние записи
  - **Эта неделя**: показать записи с понедельника по сегодня
  - **Этот месяц**: показать записи с 1-го числа по сегодня

### Список записей

Записи сгруппированы по датам и отображаются в таблице:
- Время начала
- Время окончания (или «в процессе» для активных записей)
- Название активности и описание
- Длительность

**Примечание**: Пересекающиеся записи выделяются красным цветом.

### Нижняя панель

- **Общее время**: итог за выбранный период
- Нажмите на строку **Итого**, чтобы развернуть/свернуть разбивку по активностям

## Учёт времени

### Запуск таймера

1. Нажмите кнопку **Старт**
2. Введите название активности
3. При необходимости добавьте описание
4. Нажмите **Сохранить** или клавишу **Enter**

Таймер запускается немедленно, и запись появляется в списке как «в процессе».

### Остановка таймера

Нажмите кнопку **Стоп**, чтобы завершить текущую сессию. Время окончания записывается автоматически.

### Быстрое добавление из трея

Щёлкните правой кнопкой мыши по иконке в трее и выберите **Быстрое добавление**, чтобы начать отслеживание без открытия главного окна.

---

## Управление записями

### Редактирование записи

1. Нажмите на любую запись в списке
2. Откроется диалог редактирования:
   - Название активности
   - Описание
   - Дата и время начала
   - Дата и время окончания (или флажок «В процессе»)
3. Внесите изменения
4. Нажмите **Сохранить**

### Удаление записи

1. Нажмите на запись, чтобы открыть диалог редактирования
2. Нажмите **Удалить**
3. Подтвердите удаление

### Создание записи вручную

Используйте кнопку «Старт» для создания записей с конкретным временем:
1. Нажмите **Старт**
2. Заполните название и описание
3. Установите дату и время начала
4. Снимите флажок «В процессе» и установите дату/время окончания
5. Нажмите **Сохранить**

## Просмотр статистики

### Разбивка по активностям

1. Выберите нужный период
2. Нажмите на строку **Итого** внизу окна
3. Развернётся разбивка:
   - Каждая активность с общим временем
   - Сортировка по длительности (сначала самые длинные)
   - Индикаторы статуса экспорта

### Анализ периодов

Используйте календари или быстрые фильтры для анализа разных периодов. Итоги и разбивка обновляются автоматически.

## Интеграция с YouTrack

### Начальная настройка

1. Откройте **Настройки**
2. Введите URL вашего YouTrack (например, `https://youtrack.company.com`)
3. Введите API-токен (создайте в настройках пользователя YouTrack)
4. Настройте **Псевдонимы активностей** для сопоставления с задачами:
   - Пример: «Разработка» -> «PROJ-123»

### Экспорт в YouTrack

1. Выберите период для экспорта
2. Убедитесь, что нет пересекающихся записей (выделены красным)
3. Нажмите **Экспорт в YouTrack**
4. Просмотрите превью с агрегированными записями:
   - Время группируется по активности и дате
   - Минуты округляются вверх до 10 (минимум 10)
5. Нажмите **Подтвердить** для экспорта
6. Следите за индикатором прогресса
7. Результаты отобразятся в диалоге успеха

### Журнал экспорта

- Откройте **Настройки** и нажмите **Журнал экспорта** для просмотра истории
- В журнале отображаются ранее экспортированные записи со статусом
- Используйте **Очистить журнал** для удаления истории

### Устранение неполадок

- **Пересекающиеся записи**: устраните конфликты времени перед экспортом
- **Отсутствующие псевдонимы**: добавьте псевдонимы активностей в Настройках
- **Ошибки аутентификации**: проверьте, что API-токен действителен

## Импорт из KTalk

Импорт записей времени из видеоконференций KTalk.

### Как импортировать

1. Откройте веб-интерфейс KTalk в браузере
2. Откройте Инструменты разработчика (F12) -> вкладка Network (Сеть)
3. Выполните поиск конференций, чтобы инициировать API-запрос
4. Найдите запрос и скопируйте fetch()-вызов (правый клик -> Copy as fetch)
5. В Tempus нажмите **Импорт из KTalk**
6. Вставьте скопированный код в текстовое поле
7. При необходимости измените период
8. Нажмите **Импорт**

### Параметры

В **Настройках** можно включить или отключить импорт незапланированных встреч.

## Настройки

Откройте настройки, нажав кнопку **Настройки**.

### Язык

Переключение между английским и русским языками. Изменения применяются немедленно.

### Конфигурация YouTrack

- **Базовый URL**: адрес вашего YouTrack
- **Токен**: токен API-аутентификации
- **Псевдонимы активностей**: сопоставление названий активностей с ID задач

### Параметры KTalk

- **Включать незапланированные встречи**: импортировать ли незапланированные конференции

### Журнал экспорта

Просмотр и управление историей экспорта в YouTrack.

## Системный трей

При закрытии окна приложение сворачивается в системный трей.

### Иконка в трее

- Разные иконки показывают состояние: ожидание или активное отслеживание
- Обновляется каждую секунду при активном отслеживании

### Меню трея

Щёлкните правой кнопкой мыши по иконке для вызова меню:
- **Показать окно**: открыть главное окно
- **Быстрое добавление**: быстро начать отслеживание новой активности
- **Стоп**: остановить текущий таймер
- **Выход**: полностью закрыть приложение

## Советы

1. **Используйте быстрое добавление** для оперативного ввода времени без открытия главного окна
2. **Проверяйте пересечения** (красная подсветка) перед экспортом в YouTrack
3. **Настройте псевдонимы активностей** один раз для упрощения экспорта в YouTrack
4. **Используйте быстрые фильтры** (Сегодня, Эта неделя, Этот месяц) для быстрого просмотра нужных записей
5. **Разверните строку Итого**, чтобы увидеть распределение времени по активностям
